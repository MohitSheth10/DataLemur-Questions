# 🧩 Python Practice Problems

My solutions to Python coding problems from [DataLemur](https://datalemur.com) and the [CSES Problem Set](https://cses.fi/problemset/), sorted by difficulty.

## Easy Level

| Problem | What it does |
|---|---|
| **Weird Algorithm** | Takes a number n. If it's even, halves it; if it's odd, does 3n + 1. Prints every step until it reaches 1. |
| **Trailing Zeros** | Counts how many zeros are at the end of n! (n factorial). |
| **Weakest Strongest Link** | In a grid, finds the number that is the smallest in its row and the largest in its column. Returns -1 if there isn't one. |

## Medium Level

| Problem | What it does |
|---|---|
| **Longest Consecutive Sequence** | Finds the length of the longest run of consecutive numbers in a list (e.g. `[100, 4, 200, 1, 3, 2]` → 4, from 1-2-3-4). |
| **Data Conference Attendees** | Each attendee says how many *other* people share their job title. Works out the smallest possible number of people at the conference. |

## How to Run

Each file runs on its own with Python 3 and doesn't need any extra libraries:

```bash
python "Easy Level/Weird Algorithm.py"
```

Files that contain a function also include test cases in comments at the bottom. Swap one in to try it.
